# Phần 1 (Phân tích)
Chức năng là nghiệp vụ khám bệnh (đặt lịch, kê đơn); Phi chức năng là tiêu chuẩn bảo mật dữ liệu và hiệu năng hệ thống.

# Phần 2 (Triển khai)

Word: Viết SRS bảo mật y tế.

Excel: Quản lý 1000 hồ sơ theo chuẩn Database.

PowerPoint: Dùng Donut Chart tối giản báo cáo dịch bệnh.

# Phần 3 (Kiểm thử lỗi Heading)
Dùng Ctrl + Shift + N để đưa đoạn văn bị gán nhầm Heading về định dạng Normal.

Xử lý bẫy dữ liệu (Ô trống AutoFilter): Phải điền giá trị tạm (như N/A) vào các ô trống để bộ lọc không bị ngắt quãng, quét được toàn bộ bảng dữ liệu.
